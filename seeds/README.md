# seeds/

`origins-v3.json` is the catalogue of 100 origin ideas ("how everything started"). Every idea is a CONJECTURE. Each entry has its description, how the Universe Starter v3 runs it (`v2` recipe, `FAITHFUL`, `PROXY` with a note, or `NOT RUNNABLE`), the settings, the class the locked sweep gave it, and a pointer to its card in `cards/` or `dead-ends/`.

Seven ideas are descriptive only (no control in the locked protocol), so they have observations, not cards. Two are NOT RUNNABLE (46 No-boundary proposal, 83 Participatory universe).

There is no committed schema for this file yet.
