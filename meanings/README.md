# meanings/

The shared dictionary of invented symbols. One JSON file per meaning, validated by `schema/meaning.schema.json`.

A meaning is runnable only when it is bound to an operation: its `formal` field starts with `BOUND:` (or `BOUND (PROXY):`) and names the engine setting or measure that implements it. A meaning with no `formal` field, whose definition starts with `VOCABULARY`, is a word, not an operation. Cards list the meanings their settings actually switch on.

The first entries are the core terms of Prismatic Reflective Relativity (PRR), an optional lens. In the atlas today PRR adds vocabulary at the records and arrow-of-time step, not a new number.
